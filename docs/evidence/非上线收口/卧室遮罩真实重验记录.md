# 卧室遮罩局部重绘：单次真实结果

日期：2026-10-02。产品经理授权开通即梦 AI 交互编辑 inpainting，并仅提交旧卧室一张真实遮罩测试。控制台开通成功截图显示该服务处于“免费试用”；此前账号计费页显示试用 200 张、正式调用 ¥0.20/张。此次实际试用额度扣减及账单尚未核对，不把公开单价写成实付金额。

[并排审图页](卧室遮罩真实审图.html)：左侧旧卧室原照片，右侧本次模型原始图，下方是实际提交的严格结构遮罩。输入原照片缩至 4096×2731，单通道遮罩同尺寸；只有左墙下半部与地面为白色重绘区，门窗、吊顶与其余墙面为黑色保留区。隔离脚本在提交前持久化一次性标记，真实任务仅提交一次；查询已有任务没有创建第二个任务。结果保存在 `data/qa-bedroom-inpaint-20261002/`，审图副本在本目录。

初步人工检查：本次结果**保留右墙三扇窗**，左侧房门、远墙窗、吊顶与地板布局大体仍在，并生成床、床头柜、落地灯和地毯。与此前连续把三窗缩成两窗的 Seedream 整图生成相比，这张图解决了该样例最明确的窗户数量错误。床头位于远墙窗下方，审美和使用合理性需产品经理判断。黑色区域在模型原始输出中不是逐像素相同，因此此结果不能证明“硬锁房屋结构”或对其他房间稳定有效。

产品经理审图后选择“演示可接受，继续验证其他房间”。本结果只按单张结构可行性样例记录；卧室图片能否用作最终产品演示素材尚未单独判断，也未放宽对其他房间的结构要求。

另做过一次完全离线的保护区原像素回填尝试，但床头上方出现明显横向接缝，判为失败，未作为审图成品，也未接入正式流程。后端 40/40 测试通过；用户视觉验收及多房间泛化仍待确认。无额外生图调用。
