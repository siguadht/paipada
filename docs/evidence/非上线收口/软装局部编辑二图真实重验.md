两项均通过正式编辑 API 调用真实火山图像模型，图像落在独立 `data/qa-soft-v2-20261001/`；没有把 mock 当真实结果。模型输入路由的离线测试覆盖删除、改色、普通家具参考替换、指定商品替换和整体改风格。此轮真实隔离方案没有设置旧风格/家具参考，因此出图本身不能单独证明“旧参考不会回流”，该规则由离线请求测试验证。

调用后关闭隔离 API，直接检查 SQLite：两份方案均为 `front_ready`、当前第 2 版，合计四条版本记录；两张新图均可由 Pillow 解码。审图页的五张图片均经本机 HTTP 读取返回 200。

观察到边柜主要改色但未完全换结构后，已再收紧**指定商品替换**提示：新物品由商品主图决定轮廓与可见结构，先移除旧物，不得只把旧物改色。此提示变更在上述两次真实调用**之后**完成，后端 36/36 通过；其后续单图重验见下节，不能把一次改善写成所有商品均已解决。

## 2026-10-02 边柜单图重验

产品经理先回复“A”：窗帘改色通过、边柜继续优化。随后在已知单次图片费用上限约 ¥0.64、最多一次网络重试的条件下，明确授权再重验一张。隔离复制原浅木柜基底，仍选同一 Unda 商品，用收紧后的“移除旧物，以商品图决定新柜结构”提示调用正式编辑 API；不覆盖前两版。新方案 `80856fae-7d2a-4cc2-ac67-faf2bda38a90` 第 2 版文件 `80856fae-7d2a-4cc2-ac67-faf2bda38a90_edit_03b3c10c.jpg` 已放到上方对照页。

人工初审：旧柜的明显开放格消失，出现深色封闭柜门，和商品主图的结构更接近；沙发、座椅、窗和植物大体保留。但柜体宽度、柜门与把手细节仍与商品主图不同，不能称精确商品复刻。产品经理看过新旧对照后确认：**“演示可以通过，保留非精确说明”**。这只验收“能看出换了一件柜子”的演示标准，不验收准确 SKU 复刻。本次图片无重试基础费估算 ¥0.32，按授权最多一次网络重试的上限约 ¥0.64，另有少量临时存储费；准确扣费仍看火山账单。
