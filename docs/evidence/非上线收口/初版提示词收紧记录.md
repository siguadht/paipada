# 初版提示词收紧记录

日期：2026-10-01。产品经理验收上一轮茶几替换、绿植删除、窗帘改色和电视墙新机位示意后，继续处理初版结构漂移。

## 查到的问题

使用已真实测试的同一张客厅原照片和原描述、风格图、家具图组装请求时，旧版最终提示词约 417 个字符：通用结构限制、参考图用途、用户原话和质量修饰重复，且末尾“保持参考图的画面比例”可能与原房间照片比例混淆。火山[图片生成 API 文档](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)建议中文提示词不超过约 300 字，过长可能让模型忽略细节。这是可能导致门窗约束失效的因素之一，不能由此断言是唯一原因。

## 已改动

- 结构提示缩短，但仍明确保留机位、墙面、门窗数量和位置、梁柱、吊顶和地面边界；用户没要求时不自行增加电视。
- 风格图仅供材质配色光线，家具图仅供单件造型颜色；压缩重复修饰，用户原话完整保留。
- 去掉含混的“保持参考图的画面比例”，输出比例仍由原房间照片尺寸决定。
- 该真实客厅三图请求在新模板下最终提示词不超过 300 字。后端 36/36 测试通过，正式本机 API 已重启加载。

## 一次真实重验

产品经理在获知“火山 Seedream 5.0 Pro 单图约 ¥0.30，最多一次网络重试时图片费用上限约 ¥0.60，另有少量文字模型与临时存储费”后回复“继续”。据此仅对隔离方案 `c4963a77-b33d-4df5-b5b3-ef5f24673ae3` 用同一原照片、风格图、家具图及原话做一次真实初版；没有覆盖验收方案，没有追加软装编辑或 2.5D。实际扣费以火山账单为准。

[原图、前两次失败初版、这次初版与局部修正并排审图](http://127.0.0.1:8772/)。新图 `c4963a77-b33d-4df5-b5b3-ef5f24673ae3_front_be6ac177.jpg` 人工初审：左墙未凭空多门，右窗位置、顶面风口和检修口、瓷砖地面比前两次更贴近原照片；左侧有米白沙发，中间有木茶几。旧深色窗帘大体保留，设计审美仍待产品经理判断。

产品经理随后回复“可以通过”，确认这张初版的本次样例验收。旧窗帘与其他房间泛化仍按实际情况保留风险。

**一张改善样例不证明“缩短提示词必然修好门窗”，也不证明其他房间稳定。**
