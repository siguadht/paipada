# 即梦遮罩局部重绘预检

日期：2026-10-02。目标是验证旧卧室右墙三扇窗能否保持原状；本轮没有开通新服务，也没有提交模型任务。

## 已核实

- [官方接口文档](https://docs.volcengine.com/docs/JimengAI/JimengAI-interactiveeditinginpainting-interfacedocumentation?lang=zh)要求同尺寸的原图和单通道灰度遮罩。黑色保持、白色重绘；JPEG/PNG、每张不超过 4.7 MB、最大 4096×4096。与当前方舟 Seedream 是不同接口，需智能视觉服务权限。
- [官方计费页](https://docs.volcengine.com/docs/JimengAI/JimengAI-imagegenerationbillinginstructions?lang=zh)列出成功调用 ¥0.20/张，最终价格以控制台接入页为准。产品经理提供的本账号“计费购买”截图显示免费试用生图量 200 张、正式调用单价 ¥0.20/张、1 并发；当前服务仍未开通，不能据此认定该账号的免费次数已经到账。
- 原卧室图 5472×3648 超出接口最大边长。离线预处理后为 4096×2731；遮罩与其完全同尺寸、模式 `L`。为严格锁结构，输出遮罩改为默认全黑，仅开放左墙下半部及地面供床和软装生成，再用手绘轮廓确保左门、远窗和右墙三窗仍为黑色保留区。输入文件存于被 git 忽略的 `data/qa-bedroom-inpaint-20261002/`，均小于 4.7 MB。
- 新增 [离线准备脚本](../../../backend/scripts/prepare_bedroom_inpaint.py)、[一次性验证脚本](../../../backend/scripts/qa_bedroom_inpaint.py)和输入合同/防重复提交测试；后端全套 40/40 通过。验证脚本默认只查本地输入，只有显式 `--submit-once` 才会提交；请求前落盘一次性标记，结果不明也不会自动重试。当前**没有**运行提交命令，SDK 仅装入本地虚拟环境，没有加入正式后端依赖。没有把黑白遮罩冒充真实生图效果。
