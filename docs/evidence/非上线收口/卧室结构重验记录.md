# 卧室结构重验记录

日期：2026-10-02。产品经理明确授权用既有公开卧室原图和既有风格参考，在隔离目录重验一张正面图；事前披露两张输入、1.5K 输出、最多一次网络重试的图片费用上限约 ¥0.64，另有少量文字模型与临时存储费。本次直接调用正式生图服务，没有额外文字模型调用；实际金额以火山账单为准。没有覆盖原方案，也没有生成 2.5D。

原图来源和旧版见[阶段 3-2 证据包](../阶段3-2/证据包.md)。[三图并排审图](./卧室结构重验.html)：原图远墙有一组窗、右墙有一组三扇窗，左边可见房门。旧版将右窗缩小；本次真实重验仍将右墙三扇窗变为两扇。房门、远墙窗、吊顶和木地板大体保留，床与窗的相对位置仍与原图结构不符。**本次结构保持未通过。**

本次调用使用原卧室照片、同一风格参考、原房间描述和当时正式生图服务的结构提示。最终提示词连固定画质修饰约 340 字，超过火山图片生成 API 建议的约 300 字；长度可能分散模型注意力，但不能凭这一张图断定它是唯一原因。发现失败后，未继续付费调用。

随后只做离线改动：压缩固定结构说明、参考图说明和共享风格连接词，保留用户原话及共享风格内容；该卧室请求在新模板下约 313 字。后端 36/36 测试通过。**新模板没有真实出图验收，不能宣称门窗稳定。**

限制：图像模型仅靠文本与照片输入无法对门窗几何作确定性保证。继续追求严格结构时，应另行评估带空间约束的方案和费用；当前产品仍可用原图对照与点选局部修正处理失败图，但不能把修正入口算作初版一次成功。
