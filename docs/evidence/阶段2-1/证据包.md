## 一、验证地址与"照着点"步骤（产品经理可自行核对）

**访问地址（服务器已在本机运行）**：http://127.0.0.1:8000/

1. 打开上面的地址，看到「邀请码登录」页。
2. 填入已分发的邀请码，点「登录」→ 看到主界面（上传 + 描述 + 历史）。
3. 选一张房间照片（JPG/PNG/WebP，≤10MB），描述框输入"奶油风，有猫，3 万预算，要温馨"，点「生成」。
4. 观察任务进度：`understanding`（看到 LLM 返回的结构化 JSON）→ `rendering` → `review`。
5. 看到两张图（当前为 mock 占位图）+ 设计说明 + 热点，出现「通过 / 驳回换风格」按钮。
6. 点「通过」，评分填 5 → 任务变 `completed`；历史列表出现该条记录。
7. （可选）点「驳回换风格」→ 任务回到 understanding 重新生成；连续驳回 3 次 → `failed`。

**若想自己启动服务**（我这边停了之后）：
```bash
cd projects/拍拍搭/backend
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```
