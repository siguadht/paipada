# 阶段 3-1：效果图编辑交互重排

日期：2026-10-01。产品经理已认可“开始创作”页，反馈原“效果图编辑”页交互感差。本次只调整 `/ui-preview` 的效果图编辑页，阶段仍待验收。

## 打开体验

访问 http://127.0.0.1:3000/ui-preview ，点击顶部“效果图编辑”。鼠标移到沙发上可看整件弹起，点沙发后，操作条出现在沙发附近。点“替换 / 改色 / 删除”，桌面在图旁、手机在底部打开对应输入。顶部“修改整体需求”可直接描述首版问题。点图片空白处可以退出家具选中。

以上操作仅演示交互。预览不会调用模型，不会真的替换、改色、删除或生成新版本。正式业务流程仍在 `/`。

## 核查

- 桌面实测悬停沙发整件弹起，点选出现图片上操作条；点“改色”后图旁面板打开。快速选色“浅灰”能填入具体修改描述。整体改需求入口可打开相应输入。
- 手机实测轻点沙发选中，点“改色”打开底部面板；390 px 页面未横向溢出。图片保持原色。
- `npm run typecheck`、`npm run lint`、`npm run build` 通过。
- 目前只具备沙发透明图层；其他家具的整件选中与真实图片修改需要另行接入，不能以本预览冒充正式能力。
