# 阶段 3-1：创作布局重排检查点

日期：2026-10-01。状态：待产品经理视觉反馈，阶段 3-1 未验收。

## 自己打开看

打开 http://127.0.0.1:3000/ui-preview ，无需邀请码。首屏看“开始创作”：完整原房间图在上，修改描述紧随其下，风格和家具参考为两个独立入口。点顶栏“效果图编辑”：原色效果图居中；鼠标移到沙发上或在手机轻点沙发，整件沙发弹起，出现替换、改色、删除。点右上“修改需求”，可填写首版哪里不对。

这只是 UI 交互稿：点击预览生成、局部编辑或重新生成不会调用模型或保存图片。正式生成链路仍在根路径 `/`。

## 核查结果与边界

- 本次只改变独立 `/ui-preview` 路由的布局；黑白灰界面色彩保留，照片与沙发图层按原色显示，浏览器计算样式 `filter: none`。
- 桌面 1200 px、手机 390 px 浏览器实际看过创作页与编辑页；手机 `documentElement.scrollWidth` 未超过视口宽度。手机点击沙发后图上操作条出现。
- `npm run typecheck`、`npm run lint`、`npm run build` 均通过；`/ui-preview` 返回 HTTP 200。
- 参考了 [MiniMax Design](https://design.minimax.cn/) 的作品呈现方式和 [小云雀](https://xyq.jianying.com/) 的画面与输入关系。当前结构以小云雀的创作入口更适配拍拍搭为设计判断，没有复制两家的品牌素材或页面代码。
- 目前只有沙发具备可弹起的透明图层。整图修改与家具按钮在此页只演示操作路径；真正生图和全部家具轮廓仍是阶段 3-1 的后续工作。
