# 六类软装商品图样稿

2026-09-30 经产品经理明确授权生成六张 1.5K AI 示意图，各类别一张，未继续生成其余 22 件。

## 预览

- 浏览器打开 http://127.0.0.1:8766/ 。本地服务从本目录启动：`python3 -m http.server 8766 --bind 127.0.0.1`。
- 六张均为 1536×1536 JPEG：沙发 `p001`、灯具 `p009`、绿植 `p017`、茶几 `p022`、地毯 `p025`、柜体 `p027`。
- 统一为浅米白无缝背景、独立单品、棚拍光线。人工逐张查看，物品基本完整，无明显文字或水印。台灯没有发光效果；茶几的视觉尺度略大，正式采用前可继续评估。

## 边界与费用

- 图片由 Seedream 5.0 Pro 生成，只是风格示意；不对应 `products.json` 里填写的真实品牌、价格、库存或可购买商品。
- 产品经理看后反馈“风格需调整，先不接入”。样稿未写入商品库 `image_url`，正式前端仍显示“商品图待补”；这六张仅保留为第一轮对照。
- 官方 [火山方舟模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh) 载明 Seedream 5.0 Pro 单图生成在 1.5K 及以下为 ¥0.30/张；六张预估输出费用 ¥1.80，实际以火山账单为准。脚本不自动重试生成请求，也不输出密钥或远端错误响应。
- 生成脚本：`backend/scripts/generate_product_preview.py`。脚本会跳过已存在的样稿，避免重复调用。
