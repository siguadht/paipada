## 自己检查

1. 打开预览页，看到原色房间大图，下方依次是“开始创作 / 效果图编辑”、创作框与三个参考图入口。
2. 在创作框中改写要求，选下方示例，观察文本自动填入；点“预览效果图编辑”。
3. 在效果图编辑页描述整张图的问题，也可在沙发上悬停、点选，再选替换、改色或删除。图上操作与下方输入框联动。
4. 桌面左侧使用“开始创作 / 效果图编辑”切换，点“灵感示例”滚到模板；点“历史记录”进入正式历史页。手机点左上角菜单打开侧栏，选一项后自动收起。
5. 点击“返回现有页面”可回到当前正式流程。
