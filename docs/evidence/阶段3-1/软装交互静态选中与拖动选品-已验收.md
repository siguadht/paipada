# 软装交互改版（产品经理已确认）

## 打开页面

本机打开 [客厅第 2 版](http://127.0.0.1:3000/design/c221ac2b-da08-40d7-91db-f9d42f7ee490?interaction=hover-actions-20261001)。如未登录，使用项目已有演示邀请码；邀请码本身不写进文档。

## 照着点

1. 鼠标移到左侧沙发：沙发原位出现轮廓反馈，旁边直接显示“替换、改色、删除”。鼠标移到操作栏时按钮保持可点。
2. 不点击沙发，直接点图上的“替换”：沙发被选中，选品窗从沙发旁打开。也可点“删除”查看已选中状态，不要提交生成。
3. 按住选品窗标题处的拖动把手，把窗口拖到画面右侧；也可聚焦把手后用方向键移动。
4. 选择任意演示商品：窗口显示已选商品，下方修改描述同步更新；本次验收不要点“生成修改”。
5. 手机窄屏：点沙发、点替换，选品窗从屏幕下方打开，按住标题可上下拖动。
