## 自己打开核对

1. 打开 http://127.0.0.1:3000/ ，用此前分发的邀请码登录。
2. 上传一张房间照片，写一句改造想法，点击“生成我的效果图”。首次只出现正面效果图，2.5D 页签暂不可用。
3. 点击图中软装位置，观察局部 Q 弹反馈；在右侧选“删除软装 / 替换软装 / 修改颜色”，或者直接选“整体风格”。当前本机演示模式的替换面板按类别展示六件带产品主图的品牌商品，可点“查看品牌原页”；选商品会填入造型参考描述。未核实的价格和库存不展示。
4. 提交一次修改，等待新图，查看“版本记录”并恢复旧版。确认满意后点击“确认效果图，生成 2.5D”；完成后 2.5D 页签可用。2.5D 下方应显示来源正面图版本。点击“标注商品”→点击图中的物品位置→挑一件参考单品→“保存这个热点”；点图上的编号可看商品卡，也可删除。热点由你亲自标注，不是模型自动识别。当前版本不可重复恢复，以免误清除 2.5D。
5. 打开“我的方案”，确认可以回到刚才的方案。浏览器刷新后，版本与结果应仍在。

当前前端 3000 连接新编辑 API 8002；旧阶段 2 后端验收页仍在 8000。若本地服务已结束，按项目 README 的步骤重新启动。
