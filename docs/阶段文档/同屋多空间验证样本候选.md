日期：2026-10-01。阶段 3-2 已验证“同一家庭项目下两房间逐个生成和 2.5D 可回看”的技术流程，但当时的客厅是用户样例、卧室是另一处公开房间，不能用来证明真实同屋一致性。

## 已选：用户提供两张新的毛坯房原照片

产品经理于 2026-10-01 原拟提供两张新的毛坯房照片，随后改为要求从摄图网寻找。收到最终可用原图后，先核对是否来自同一套房、是否足以看清空间结构，以及实际分辨率与格式；再在隔离方案分别生成正面图，以第一间确认图作为第二间共享风格参考，核对空间结构、材质、色温与家具体系。需单独说明素材取得和模型费用并获授权后才能调用模型。若两张不属同一套房，则只能验证两个房间共享风格的产品流程，不能宣称同屋一致性。

### 摄图网初筛（尚非可用生成原图）

逐张看过[大空间、带楼梯的毛坯房](https://699pic.com/tupian-501231620.html)（ID 501231620）与[较小空间、双窗的毛坯房](https://699pic.com/tupian-501238422.html)（ID 501238422）。两者都是实拍，门窗、墙面和梁柱可见，分别可做客厅与小房间的结构测试；页面摄影者均标为 IVAN LIN。**同一摄影者不等于同一套房**，摄图网页面未给可核对的房屋关联，因此不能以此宣称“真实同屋多空间”验证。它们是两个不同大小空间的备选样本。

目前仅取得带摄图网水印的低清预览用于人工筛选。两页均有个人/企业授权和单张购买入口，未购买、未下载无水印原图，也未送进模型。若选用，先确认素材费用和授权方式；不能拿水印预览冒充正式输入。另查看的 ID 501332718、501332726、501332727 以及 501664427–429 基本是各自同一大空间的不同机位，不能当客厅和卧室两间房；部分页面仅企业专享，故排除。

### 最终演示输入改为对话里选定的两张

产品经理随后在对话里附上另两张图片并回复“就用这个”。第一张是大开间，第二张是较窄空房；两张都可看到门窗、地面、墙面、吊顶、空调/消防等固定结构，适合检验生成时是否保持结构。它们看起来更像商用办公空间，且照片本身不能证明同一物业。按产品经理选择，仅作为**商用空间双房间演示**，不作为住宅毛坯或真实同屋一致性的证据。

产品经理随后给出两张本机原图路径。已复制至 `data/qa-business-space-20261001/large_room.jpg` 与 `small_room.jpg`；经文件识别及 Pillow 解码校验，均为 1706×1279 的有效 JPEG，大小分别 176297 与 143237 字节，低于项目 10MB 上传限制。它们是微信转存图，当前没有可核对的原摄图网素材编号或同物业证明，测试结论继续限于商用空间双房间演示。没有购买上述摄图网候选；本轮隔离付费生图已获授权并完成，结果见 `docs/evidence/非上线收口/商用双空间真实记录.md`。

按现有正式接口，只有首间正面图确认并生成 2.5D、状态为 `completed` 后，`/homes/{id}/style-from-space/{space_id}` 才能把它设为第二间的风格参考。本轮已按此链路生成三张输出：大空间正面图、大空间 2.5D、小空间正面图，并核对第二间实际引用第一间正面图。两张输入的宽高比约 4:3，后端输出为 1280×960，低于 1.5K。事前按[火山方舟官方价格表](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)估算图片费用上限约 ¥1.84，产品经理回复“继续”后执行；实际账单仍待核对。产品经理已看五图对照页并回复“通过，整体还行”，仅验收本轮样例，不证明同屋或任意空间生成稳定。

## 备用：公开同屋样本

Wikimedia Commons 收录同一栋 Paul Schweikher House and Studio 的多张客厅、卧室照片。最初按标题找到的[客厅照片](https://commons.wikimedia.org/wiki/File:Living_Room,_Paul_Schweiker_House_and_Studio,_Meacham_Road,_Schaumburg,_IL_-_54209457512.jpg)主要是天花板，[主卧照片](https://commons.wikimedia.org/wiki/File:Master_Bedroom,_Paul_Schweiker_House_and_Studio,_Meacham_Road,_Schaumburg,_IL_-_54210601900.jpg)主要是书架；已实际下载看图，**两张均排除**，不能拿标题当作整屋原图。

重新逐张查看后，选出[客厅全景](https://commons.wikimedia.org/wiki/File:Living_Room,_Paul_Schweiker_House_and_Studio,_Meacham_Road,_Schaumburg,_IL_-_54210620494.jpg)与[主卧全景](https://commons.wikimedia.org/wiki/File:Master_Bedroom,_Paul_Schweiker_House_and_Studio,_Meacham_Road,_Schaumburg,_IL_-_54210195756.jpg)。两张原图已下载到本机忽略目录 `data/qa-same-house-20261001/` 并人工看图：客厅可见沙发、茶几、座椅、砖墙和窗；卧室可见床、窗、墙面与吊顶。文件页均署名 w_lemay，许可 CC BY-SA 2.0；展示原图或改图时须署名、链接来源与许可并说明改动。两张明确来自同一栋房屋，但属于已装修的现代主义博物馆住宅，适合验证共享风格的技术链路，**不能**代表普通业主旧房改造质量，也不能验证用户自己的同屋照片。

选择备选时，仅在隔离方案做两张正面图，先审结构与风格，再决定是否有必要重做 2.5D。按当日火山 Seedream 5.0 Pro 官方 ≤1.5K 单图 ¥0.30、每张最多一次网络重试估算，两张图片上限约 ¥1.20，另有少量文字模型与临时存储费用；正式调用前仍需产品经理按具体方案授权。原图已下载，**尚未调用模型**。
