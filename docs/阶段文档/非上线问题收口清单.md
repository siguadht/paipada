# 非上线问题收口清单

日期：2026-10-01。范围为本地产品体验和生成结果；阶段 4 的云部署、线上图片许可、线上商品价格/库存和生产权限验收另行处理。

| --- | --- | --- |
| 软装替换的指定商品不准 | 选中本机演示商品后，后端核对商品 ID 和本地主图，把主图作为模型额外参考；真实沙发替换样例的造型与主图接近。边柜首次只变深，产品经理未通过；收紧“先移除旧物，以商品图决定新物结构”后真实重验一张，旧开放格消失、深色柜门更完整，产品经理按演示标准通过 | 尺寸及细节仍非精确 SKU，不能承诺所有商品泛化；若要真实商品级还原，需另定验收标准与技术方案 |
| 家具删除、改色 | 保留已验收的悬停菜单与可拖动图旁选品；沙发改色、删除重验可用。另完成茶几指定商品替换、落地绿植删除、窗帘改色三类已验收样例。后续删除、改色只使用当前效果图，不再附带风格或旧家具参考；改色提示要求目标物品清楚呈现指定颜色。按新提示真实重验窗帘，左右两幅均明显变浅 | 新窗帘图待产品经理审图；隔离真实方案未设置旧参考图，参考路由本身由离线请求测试验证；各类单次样例不代表全部家具稳定可改 |
| 初版与整图重做随机改门窗、地面、机位 | 两条生图路径明确要求保留原照片结构；另接入“点错误位置，参照原照片修正这一处”。客厅旧图一次局部修正去掉多余门，精简提示词后的同图初版获验收。旧卧室另做一次隔离重验仍把右墙三扇窗变成两扇；失败后再压缩固定提示词，后端 36/36 | 卧室结构真实重验未通过，离线提示词改动未出图；不能宣称不同房间稳定保留门窗 |
| 2.5D 精度 | 当前为由已确认正面图生成的视觉示意，版本来源可追溯 | 严格匹配户型需要户型图或尺寸约束及新方案；不能把斜俯视图称为精确轴测 |
| 全屋一致性 | 已有共享风格快照和两空间生成流程；产品经理指定两张商用空房图，第一间正面图及 2.5D、第二间引用第一间结果的正面图均已真实生成并获“整体还行”验收 | 两张照片未证实同一物业，不能称真实同屋验证；第二间尚未生成 2.5D |
| 旧图交互 | 已准备图层的版本可悬停整件；未准备版本可点位编辑，不自动收费 | 其他旧图若也要求整件轮廓，需逐版拆层并单独确认费用 |
| 电视墙原照片未入镜 | 重生入口增加“换个机位看电视墙 · 示意”，默认仍沿用原照片机位；隔离方案真实返回一张斜向电视墙概念图 | 产品经理审图；缺少该墙的原照片，不能把示意当作户型或结构还原；窗帘与挂画没有完全满足描述 |

本轮离线验证：后端 35/35；前端 `typecheck`、`lint`、`build` 全通过。首次真实初版图把电视放到窗前；删掉强制电视墙规则后再生成，窗前电视消失但多出一扇门，结构保持仍失败，见[首轮真实记录](../evidence/非上线收口/首轮真实生图记录.md)。新增[局部结构修正实测](../evidence/非上线收口/结构局部修正离线记录.md)在这一张样例上去掉了门，不能据此把初版生成的结构问题标为全部解决。

软装三操作已在隔离方案上真实调用：指定商品替换、改色，以及修正后的删除重验样例可用，具体结果见[软装三操作记录](../evidence/非上线收口/软装三操作真实记录.md)；[其他品类三操作](../evidence/非上线收口/其他软装品类真实记录.md)已出图。桌面与 390 px 手机的删除描述入口已复核。[电视墙新机位示意](../evidence/非上线收口/电视墙新机位示意真实记录.md)已出图但非结构证据。两次初版的结构保持均未达标，因此非上线质量收口仍未完成。

后续优先解决初版生成时原照片门窗、墙体与机位的结构保持；在产品经理审完现有图后决定哪些软装仍需优化，确认正面图后再核查对应 2.5D。真实“同一套房多空间”一致性需要同屋第二空间照片，当前公开卧室无法充当同屋证据。每张图保留来源、提示词、原图对照及产品经理评分；遇到明显失败先停，不连续烧钱。新一轮付费调用须另行核算授权，最终费用以火山账单为准。
