# 模型评测报告｜阶段 2-2 前置

> 项目：拍拍搭 · 日期：2026-09-29
> 方法：真实 Key 实测候选模型，样例 = 5 条真实风格描述；生图 = 正面效果图 + 图生图各 1 张。

## 一、LLM（理解意图）评测结果
| 模型 | 合规率 | 平均耗时 | 结论 |
| --- | --- | --- | --- |
| 豆包 doubao-seed-2-1-turbo | 1/1 可用 | **176s** | ✗ 太慢（VLM 生成极慢），淘汰 |
| DeepSeek deepseek-v4-1-flash | **2/3** | 10.5s | ✗ 推理模型，1 条 JSON 被截断（推理 token 吃掉额度） |
| **GLM glm-5-3-flash** | **3/3** | 16s | ✅ **推荐**：字段完整、收尾约束全遵守、无推理开销 |

> 结论：LLM 选 **glm-5-3-flash-260828**。注意 PRD"LLM ≤3s"目标实测无法达到（最快也 ~10s），见下"性能对照"。

## 二、生图（即梦 Seedream 5.0 Pro）评测结果
| 方式 | 耗时 | 结果 |
| --- | --- | --- |
| 文生图 | ~21s | ✅ 出图成功（样例存 `data/generated/eval_front_t2i.jpg`） |
| 图生图（参考图 URL） | ~72s | ✅ 出图成功（样例存 `data/generated/eval_front_i2i.jpg`） |
| 图生图（base64 传图） | 400 | ✗ 接口只认**公开 URL**，不认 base64 |

> 关键发现：即梦图生图**必须传入照片的公开 URL**，本地照片要先传到对象存储（火山 TOS）才能用；且图生图 72s、文生图 21s，都超 PRD"生图 ≤20s"。

## 三、性能 vs PRD 目标（如实对照）
| 指标 | PRD 目标 | 实测（最优） |
| --- | --- | --- |
| LLM 理解 | ≤3s | ~16s（glm） |
| 生图（文生图） | ≤20s | ~21s |
| 生图（图生图） | ≤20s | ~72s |
| 总流程 | ≤30s | ~1–2 分钟（取决于生图方式） |

## 四、推荐结论与待产品经理决策（见决策卡）
- LLM：glm-5-3-flash（推荐）。
- 生图方式与性能目标放宽、是否开通 TOS，待产品经理拍板（见下方决策卡）。
