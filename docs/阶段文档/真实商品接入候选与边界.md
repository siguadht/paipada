## 接入判断

1. 当前 `backend/app/data/products.json` 的 28 件是阶段 2 为验证流程而建的示意资料，名称、品牌、价格并未逐项对应真实 SKU。不能只给这些卡片贴上品牌图，造成错配。
2. 宜家中国[网站条款](https://www.ikea.cn/cn/en/customer-service/terms-conditions/)写明其图片等内容的版权归属，其他网站使用需先取得同意。故只保留官方链接与货号，不下载或复制商品图进项目正式前端。
3. 上述商品页在未指定配送地区时展示“商品暂时缺货”和“选择地址”，不能据此断言全国无货，也不能宣称当前地区可买。正式卡片需要地区或库存状态来源；无可靠数据时只显示“前往官方页查看”，不显示“现货”。
4. 预览用的 Ferm Living 与 The Sill 产品证明了主图的审美方向，但主要面向欧美市场，也未获得在拍拍搭内使用图片的许可。它们不直接映射为中国用户的可购买 SKU。

## 下一步建议

先以有官方链接和型号的商品为候选，拿到图片展示许可或符合条件的官方推广素材渠道后，再把少量已核实 SKU 接进商品卡。每张卡应分别记录商品 ID、来源 URL、来源名称、图片授权依据、核查时间和价格/库存展示方式。首批验证可先做 2–3 件，待图、链接、跳转和移动端体验通过后再扩展到其余类别。
