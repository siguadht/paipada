# 本机真实商品卡演示｜阶段 3-1

更新：2026-10-01。产品经理明确先做产品演示，是否上线以后决定。本机目录从最初六张扩充到 18 张品牌产品图，各图对应独立商品原页；这不是图片使用授权或正式商品合作。

## 演示内容

- 效果图“替换软装”面板、2.5D“标注商品”选择面板现在可按七类浏览品牌产品主图。每张卡展示真实品牌、商品名称、颜色/材质和品牌原页链接；不显示未经核实的人民币价格、库存或“中国可购买”承诺。
- 选商品后，编辑框填入“参考该商品造型与颜色”的描述，仍由真实模型生成下一版图片；不保证生成图与品牌 SKU 完全一致。
- 2.5D 热点仍由用户亲自点图标注。保存后点热点可看该商品的图片、名称和品牌原页。热点只说明用户的搭配参考，不冒充图像识别结果。
- 原有 28 件示意资料保留在后端；演示模式的目录响应包含它们以便回看历史热点，但页面选品只展示 18 件演示商品。关闭演示开关后仍是原有示意资料。

## 18 件商品与图片

最初六件商品链接与来源记录于[品牌主图方向说明](../evidence/阶段3-1/品牌产品主图参考/说明.md)。新增 12 件商品和图片来自 Ferm Living、The Sill 官方商品页；每件的独立商品 ID、品牌原页链接、图片路径见 `backend/app/data/demo_products.json`。18 张图片均存于 `frontend/public/demo-products/`，与目录条目一一对应。图片目录被根 `.gitignore` 排除，未加入仓库；演示 HTML 和图片不能当作已获正式使用许可。

## 本机运行与退出演示

1. 项目根目录 `.env` 中设置 `DEMO_PRODUCT_CATALOG=1`。本机当前已设置，密钥内容未打印。
2. 启动后端 8002 和前端 3000。打开 http://127.0.0.1:3000/ ，用已有邀请码登录，进入已有方案或新建方案；在效果图点软装后选“替换软装”，或在完成的 2.5D 图点“标注商品”。
3. 若之后不再演示，把 `DEMO_PRODUCT_CATALOG=0` 并重启后端；如需移除本地图片，可删除 `frontend/public/demo-products/`。已保存的演示商品热点不会被自动删除，再次启用开关可回看。

正式上线前需重新确认图片许可、目标地区购买可达性和正式商品数据；不能把本机演示目录直接作为线上素材包。
