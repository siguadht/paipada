2026-10-01 修正与实测：新生成与整图重做始终加入原照片结构约束，点位修改加入未选区域保持约束；点选本机演示商品后，局部替换会把该商品主图作为额外参考图传入模型，并由后端校验商品 ID 与本地图。34 项后端测试、前端类型检查、Lint、构建已通过。两次真实初版图分别出现电视挡窗、凭空多门；后一张经图上点选、参照原照片局部修正后，门洞消失，沙发与右窗大体保留。**初版整图的结构保持仍未达标**。隔离软装样例的选品替换与改色可用，删除首次失败，修正后单次重验沙发消失；不能据此承诺所有商品精确复刻或所有家具都能稳定修改。结果见[四图结构对照](../evidence/非上线收口/结构局部修正离线记录.md)与[软装编辑对照](../evidence/非上线收口/软装三操作真实记录.md)。

整件家具悬停和图旁可拖动选品已正式接入并获产品经理验收；有按版图层数据时显示整件轮廓，没有时保留点位编辑，详见[最新交互验收记录](../evidence/阶段3-1/软装交互静态选中与拖动选品-已验收.md)。任何新的付费生图或拆层验证仍须先告知预计费用并取得授权。
