# 真实商品图片授权来源核查｜阶段 3-1

更新：2026-09-30。产品经理选择继续寻找可在拍拍搭展示的真实商品素材。本轮只核查公开可见的官方条款与接入入口；没有注册联盟、取得授权或下载商品图片。因此**目前没有一组可直接进入正式商品卡的品牌图片**。

## 核查结果

| 路径 | 已核实的能力 | 当前缺口 | 结论 |
| --- | --- | --- | --- |
| [京东联盟开放平台](https://union.jd.com/openplatform) | 旧[官方接口说明](https://jos.jd.com/jdunion)记载 `jd.union.open.goods.promotiongoodsinfo.query` 可按 SKU 返回推广商品名称、主图、类目和价格，通常用于媒体侧展示商品详情；国内购买链路与拍拍搭目标用户匹配 | 用户目前没有联盟账户；需从联盟独立入口核对新平台接口、账户/API 权限、网站推广资格和具体图片使用范围。不能仅凭 API 返回图片就认定拥有复制、缓存、改图权限 | **后续接入路径，当前不宜作为图片上线前提** |
| [淘宝联盟渠道服务商条款](https://terms.alicdn.com/legal-agreement/terms/b_end_product_protocol/20230509193217510/20230509193217510.html)及[爆料信息使用须知](https://terms.alicdn.com/legal-agreement/terms/b_end_product_protocol/20230919195310890/20230919195310890.html) | 联盟有商品选品和推广信息；爆料信息包含图片，使用限定在联盟相关业务及对应商品链接推广 | 需要适合拍拍搭的推广者身份/接口权限和具体素材授权。不能把商家上传给平台的授权直接解释成拍拍搭已获授权 | **备选，待账户和场景核实** |
| [班兰家具官网](https://www.banlan.com.cn/) | 国内品牌，官网展示沙发、桌几、柜架等具体产品，提供“授权经销商&设计师 / 商业合作”入口和官方联系方式 | 官网未公开授予第三方应用展示产品图片的许可；灯、绿植、地毯也不能靠该品牌补齐 | **适合直接向品牌申请少量产品图许可** |
| [Adoreshome 联盟条款](https://ui.awin.com/advertiser-terms/125478/brand) | 明确要求推广者使用通过 Awin 提供的官方商品/生活方式图片，并给出品牌素材联系渠道 | 必须先获批为推广者；销售地区与中国用户的购买可达性尚未确认 | **可作授权形式参考，不作为当前国内商品库来源** |
| [宜家中国网站条款](https://www.ikea.cn/cn/en/customer-service/terms-conditions/) | 国内商品页及货号可核实 | 其他网站使用图片需先征得同意；上轮六件候选的地区库存也未核实 | **继续保留链接候选，不接图** |

京东企业业务 VOP 的[单独协议](https://vop.jd.com/reg/agreement)明确要求应用对外展示商品信息时取得相关权利人许可；它**不是京东联盟的协议**，不能拿它代替联盟条款，也不能推断联盟已授权或一律禁止。本轮没有查到可公开核验、无需账户审核且同时覆盖“国内真实在售商品 + 官方产品主图 + 拍拍搭站内展示”的完整授权。

### 2026-09-30 接入入口复核

- 京东[官方迁移公告](https://jos.jd.com/doc/channel.htm?id=864)称旧宙斯入口已迁移，联盟业务应走[京东联盟独立开放平台](https://union.jd.com/openplatform)。公告中“新建应用仅企业账号”针对**京东商家开放平台**，不能直接推断联盟独立平台也只接受企业。
- 京东[联盟官方介绍与 FAQ](https://jos.jd.com/jdunion)提到个人联盟账户，但也说明**未通过工信部备案的网站不能在联盟后台验证**。拍拍搭目前只有本地预览，没有可用于该验证的正式备案站点。这个 FAQ 页面可能比新平台规则旧，具体以联盟独立平台当前页面和审核答复为准。
- 产品经理确认暂无联盟账户。当前不要求其注册或提交实名资料；先走更直接的品牌素材许可沟通，待网站上线条件明确后再评估联盟申请。

## 推荐落地顺序

1. 目前先向班兰等品牌申请**明确写出“在拍拍搭网页商品卡展示官网产品主图并链接官方购买页”的许可**。回复里还要明确范围、期限、是否能缓存或裁切、撤回机制。
2. 待拍拍搭具备联盟审核所需的网站条件后，再核实京东联盟独立平台当前规则：申请账户和 API 权限、确认商品卡图片的使用范围。获准后只选 2–3 件具体 SKU 验证，不批量替换 28 件示意卡片。
3. 在得到素材使用依据前，前端继续保留示意卡。正式接入时商品图、商品名、SKU、品牌、来源链接、许可依据作为同一条记录；价格和库存没有可靠实时来源时不展示“现货/固定价”。
