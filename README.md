# 拍拍搭（SnapSpace）· AI 软装 AIGC

> **公开源码说明**：本仓库提供拍拍搭的代码、配置样例与文字文档。邀请码、密钥、本地数据库、用户房间照片、生成图片、审图截图和品牌商品主图没有公开。部分历史证据文档引用本机图片，因此公开副本中的图片链接不可用。克隆后请使用自己的测试图片；若未另行准备演示商品图，请保持 `DEMO_PRODUCT_CATALOG=0`。本仓库公开不代表品牌商品图片取得了再分发许可。


上传房间照片，先生成并编辑正面效果图；确认满意后，再从当前版本生成 2.5D 方案。新版页面在确认前先显示原图对照与门窗、墙地面、机位核对；发现结构错误可回到效果图点选修正。阶段 3-1 单空间与阶段 3-2 全屋多空间的约定范围均已获产品经理验收，**整个项目尚未完成**：初版门窗保持不稳定、未拆层版本的交互限制、正式商品图片许可与上线准备仍有待办。

## 目录结构
```
拍拍搭/
├── backend/          # FastAPI 后端（含最小验收界面 static/index.html）
├── frontend/         # Next.js 正式前端（上传、点选编辑、版本、2.5D）
├── data/             # SQLite 数据库 + 上传图 + 生成图（gitignore）
├── docs/             # PRD、项目状态、阶段文档、证据包
├── .env.example      # 配置模板（复制为 .env 填写）
└── README.md
```

## 启动（后端）
```bash
cd backend
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```
浏览器打开 http://127.0.0.1:8000/ 即是最小验收界面。

实际交互：邀请码登录 → 上传照片并描述 → 等正面图 → 若首版不满意，在效果图下方点“反馈问题，重新生成”，描述哪里出错，再从原照片生成整张新版；也可点击图中软装位置执行删除／替换／改色，或修改整体风格 → 查看和恢复版本 → 确认效果图 → 生成 2.5D。重新生成会调用模型、计入每方案 8 次修改上限；提交前会显示提示，旧版保留。替换面板可按类别选单品并填入编辑描述；2.5D 页可看来源正面图版本，并按“标注商品”在图片上点位置、选单品、保存热点。点编号查看卡片，可删除；热点随当前图片持久保存，切换正面版本后失效。热点由用户标注，不是自动识别。

当前本机开启了[28 件真实商品卡演示](docs/阶段文档/本机商品演示接入.md)：图片与商品名对应品牌原页，可在替换面板及 2.5D 热点卡查看；新增单椅、餐椅和床架等类别。不显示未经核实的价格或库存。素材只在被 Git 忽略的本机目录，未获得正式上线的图片许可。关闭 `.env` 中的 `DEMO_PRODUCT_CATALOG` 并重启后端，可恢复原 28 件示意卡。

## 环境配置
把 `.env.example` 复制为项目根目录 `.env`，填：
- `ARK_API_KEY`：火山方舟 API Key（LLM + 即梦共用一个；**开发期可不填，走 mock**）

- `JWT_SECRET`：改成一长串随机字符串
